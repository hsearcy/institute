Mini-game seeds (the "D" part)

Inside the world, certain locations open into a quick 90-second mini-game. AI picks which one based on what skill needs reps.

🎣

Number Pond

Fish leap out with numbers. Say the one that completes the equation.

🏗️

Block Tower

Stack blocks; tower height = sum of voice answers. Beat your record.

🧙

Spell Cast

Defeat a goblin by saying the right number sequence. Skip-counting practice.

🍪

Cookie Share

Divide cookies between friends. Beginning fractions / division.

Two profiles, same world

6yo profile

Problems start at +/- within 10. AI escalates (within 20, then place value, skip counting). Tutor uses fewer hints, faster pace, more text on screen.

4yo profile

Problems start at counting + number recognition (1–10). Tutor narrates everything, waits longer, celebrates more. Answers can be tapped if voice fails. Same world, different gates.

What's NOT in the mockup but worth flagging:

Resource progression (wood/stone/iron — better tools unlock harder math = new biomes), parent dashboard for you to see what they've practiced, "boss" encounters (multi-step word problems with story stakes), AI-generated problems tuned to weak spots. We'll get to all of these in the spec — this mockup is just the moment-to-moment loop.
