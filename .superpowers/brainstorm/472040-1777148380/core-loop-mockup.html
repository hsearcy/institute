Two profiles, same world

6yo profile

Problems start at +/- within 10. AI escalates (within 20, then place value, skip counting). Tutor uses fewer hints, faster pace, more text on screen.

4yo profile

Problems start at counting + number recognition (1–10). Tutor narrates everything, waits longer, celebrates more. Answers can be tapped if voice fails. Same world, different gates.

What's NOT in the mockup but worth flagging: wood/stone/iron resource progression (more advanced math = better tools = new biomes), parent dashboard for you to see what they've practiced, "boss" encounters (longer multi-step problems with story stakes), and AI-generated problems tuned to weak spots. We'll get to all of these in the spec — this mockup is just the moment-to-moment loop.
