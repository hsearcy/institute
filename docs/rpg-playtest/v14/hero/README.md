# Authored Wayfarer review evidence

These are actual 1440×900 HUD recordings from isolated Chromium against a fresh
scratch profile, using normal animation updates and real question submissions.
No family profile, live server, learning tree or reward rule was modified.
The model URL was routed to the reviewed packed candidate; its SHA is recorded
in each evidence file. That geometry, rig and texture payload became the public
Wayfarer. The later cornea-only material correction removes a redundant scene
transmission pass; these older recordings are art evidence, not final performance
measurements.

The MP4s retain the recorded variable frame durations, without interpolation.
Evidence JSON includes frame timestamps, actual sampled game state and events.
Selected JPEGs are unaltered native frames, not zoomed or repainted composites.
Raw screencast transport metadata and hundreds of duplicate image files are not
committed. Movie hashes and frame counts are in `recordings.json`.
