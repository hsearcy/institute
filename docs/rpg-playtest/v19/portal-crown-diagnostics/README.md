The previous complete portal export had a small black crown notch absent from the reviewed high source. These controls isolate its cause. Removing texture inputs, clearing custom normals and using flat faces did not remove it. The high source rendered with the same flat material stayed clean. A 352-ray local geometry audit found identical source-piece hits, depth differences no larger than 2.61mm and generally matching geometric face normals. Transferring high-source split corner normals to the two corresponding low stones removed the notch without changing low vertices or UVs.

That last control broadened some flat-material shading, so it was diagnostic rather than a finished export. The subsequent two-stone normal-map repair and exact textured views are in ../portal-crown-normal-repair/. No original source scenes or failed artifacts were deleted. All MCP stages restored the caller scene.
